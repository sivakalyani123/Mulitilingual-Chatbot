# 🌐 LinguaBot — Multilingual AI Chatbot

A multilingual chatbot supporting **15+ languages** powered by the **Groq API**.
Built as part of 23AI2013 – Foundations of Natural Language Processing.

## ✨ Features
- 💬 Chat in 15+ languages (Tamil, Hindi, Arabic, Japanese, Korean & more)
- 🔍 Auto language detection using prompt engineering
- 🎤 Voice input via Web Speech API
- 💾 Persistent chat history (localStorage)
- 📊 Dashboard with live stats
- ⚙️ 4 Groq models: Llama 3.3 70B, Llama 3.1 8B, Mixtral 8×7B, Gemma 2 9B
- 🚀 Zero backend — single HTML file, opens in any browser

## 🚀 How to Use
1. Download `LinguaBot.html`
2. Open it in any browser
3. Go to **Settings** → paste your [Groq API key](https://console.groq.com)
4. Start chatting in any language!

## 🧠 NLP Concepts Used
- Transformer architecture (Multi-Head Attention)
- BPE Tokenization (SentencePiece)
- Contextual Embeddings
- Prompt Engineering for language detection
- Dialogue State Tracking (context window)
